# รูปแบบข้อมูลคำศัพท์

คำศัพท์ทั้งหมดอยู่ในไฟล์ `data/words.json` (บันทึกแบบ UTF-8) เรียงตามลำดับที่จะสอนเป็นคำใหม่

```json
{
  "words": [
    {
      "id": "traffic",
      "word": "traffic",
      "ipa": "/ˈtræfɪk/",
      "pos": "noun",
      "meaning": "การจราจร",
      "collocation": "heavy traffic",
      "collocationTh": "รถติดหนัก",
      "cloze": "I was stuck in heavy ___ for an hour.",
      "clozeTh": "ฉันติดอยู่ในรถติดหนักนานหนึ่งชั่วโมง",
      "simple": "There is a lot of ___ today.",
      "simpleTh": "วันนี้รถเยอะมาก",
      "emoji": "🚗"
    }
  ]
}
```

| ฟิลด์ | ใช้ทำอะไร |
|---|---|
| `id` | รหัสคำ ห้ามซ้ำ และห้ามเปลี่ยนภายหลัง (ความคืบหน้าของผู้เรียนผูกกับรหัสนี้) |
| `word` | คำศัพท์ ใช้เป็นตัวเลือกใน Level 1 และเป็นเสียงอ่าน |
| `ipa` | คำอ่าน |
| `pos` | ชนิดของคำ ตัวเลือกหลอกจะเลือกคำชนิดเดียวกันก่อน |
| `meaning` | ความหมายภาษาไทย ใช้เป็นคำถาม |
| `collocation` | วลีที่ใช้คู่กันบ่อย **ต้องมีคำใน `word` อยู่ด้วย** เพราะระบบจะซ่อนคำนั้นใน Level 2 |
| `collocationTh` | คำแปลของ collocation |
| `cloze` | ประโยคสำหรับ Micro-Quiz ใช้ `___` แทนตำแหน่งคำที่หายไป |
| `clozeTh` | คำแปลประโยค cloze |
| `simple` | ประโยคง่าย ใช้บนการ์ดเฉลย และใช้แทน `cloze` เมื่อคำนั้นเป็น Leech (ใช้ `___` เหมือนกัน) |
| `simpleTh` | คำแปลประโยคง่าย |
| `emoji` | ภาพช่วยจำ แสดงเมื่อคำนั้นเป็น Leech |
| `answer` | (ไม่บังคับ) คำตอบของช่องว่าง ถ้ารูปคำต่างจาก `word` เช่น `"answer": "made"` |

## วิธีเพิ่มคำศัพท์

1. คัดลอกคำหนึ่งคำใน `data/words.json` แล้ววางต่อท้ายรายการ (อย่าลืมเครื่องหมาย `,` ระหว่างคำ)
2. แก้ทุกฟิลด์ให้เป็นคำใหม่ และตั้ง `id` ที่ไม่ซ้ำกับคำอื่น
3. Commit และ push ขึ้น GitHub เว็บจะอัปเดตเองภายในประมาณ 1 นาที
