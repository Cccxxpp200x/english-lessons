# รูปแบบข้อมูลบทเรียน

ข้อมูลทั้งหมดอยู่ในโฟลเดอร์ `data/` เป็นไฟล์ JSON (บันทึกแบบ UTF-8)

## `data/index.json` — สารบัญบทเรียน

```json
{
  "lessons": [
    { "id": "01-greetings", "title": "คำทักทาย", "titleEn": "Greetings", "level": "A1", "file": "lessons/01-greetings.json" }
  ]
}
```

| ฟิลด์ | ความหมาย |
|---|---|
| `id` | รหัสบทเรียน ต้องไม่ซ้ำ และตรงกับชื่อไฟล์ (ไม่รวม `.json`) |
| `title` | ชื่อบทเรียนภาษาไทย |
| `titleEn` | ชื่อบทเรียนภาษาอังกฤษ |
| `level` | ระดับ CEFR: `A1`, `A2`, `B1`, `B2`, `C1`, `C2` |
| `file` | ตำแหน่งไฟล์บทเรียน เทียบกับโฟลเดอร์ `data/` |

## `data/lessons/<id>.json` — เนื้อหาบทเรียน

```json
{
  "id": "01-greetings",
  "title": "คำทักทาย",
  "titleEn": "Greetings",
  "level": "A1",
  "words": [
    { "word": "Hello", "meaning": "สวัสดี", "pos": "interjection", "example": "Hello, how are you?", "exampleTh": "สวัสดี สบายดีไหม" }
  ]
}
```

| ฟิลด์ใน `words` | ความหมาย |
|---|---|
| `word` | คำหรือวลีภาษาอังกฤษ |
| `meaning` | ความหมายภาษาไทย |
| `pos` | ชนิดของคำ (noun, verb, phrase ฯลฯ) |
| `example` | ประโยคตัวอย่างภาษาอังกฤษ |
| `exampleTh` | คำแปลประโยคตัวอย่าง |

แบบทดสอบจะสุ่มตัวเลือกผิดจากคำอื่นในบทเดียวกัน แต่ละบทจึงควรมีอย่างน้อย 4 คำ

## วิธีเพิ่มบทเรียนใหม่

1. คัดลอกไฟล์ใน `data/lessons/` มาเป็นไฟล์ใหม่ เช่น `04-food.json` แล้วแก้เนื้อหา
2. เพิ่มบรรทัดใหม่ใน `data/index.json`
3. Commit และ push ขึ้น GitHub เว็บจะอัปเดตเองภายในไม่กี่นาที
