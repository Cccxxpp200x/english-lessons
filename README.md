# Active Recall English

เว็บฝึกคำศัพท์ภาษาอังกฤษ 3,000 คำที่ใช้บ่อยที่สุด สำหรับคนไทย ออกแบบให้ **นึกก่อน แล้วค่อยดูเฉลย** (Active Recall)
และทบทวนตามรอบความจำ (Spaced Repetition) ใช้ได้ทั้งมือถือ iPad และคอมพิวเตอร์

**เว็บไซต์:** https://cccxxpp200x.github.io/english-lessons/

## หลักการ

- **ไม่แสดงคำถามกับคำตอบพร้อมกัน** ต้องพยายามนึกก่อนกดเฉลย
- **ฟังก่อนเห็นตัวสะกด (Ear-first)** เสียงอ่านจะเล่นก่อนตัวสะกดภาษาอังกฤษปรากฏเสมอ
- **คำแปลไทยมาทีหลัง** คำใหม่ต้องฟังแล้วเลือกคำให้ได้ก่อนจึงเห็นความหมาย ส่วนหน้าเติมคำซ่อนคำแปลไว้เป็นคำใบ้
- **เรียนเป็นวลี (Collocation)** เช่น *heavy traffic* ไม่ใช่คำโดดๆ
- **Micro-Quiz** ต้องเติมคำในประโยคได้ก่อน คำนั้นจึงจะนับว่าผ่านในวันนี้

## ลำดับการเรียนในแต่ละวัน

| ช่วง | ทำอะไร |
|---|---|
| 1. อุ่นเครื่อง (Warm-up) | ทวนคำที่เรียนเมื่อวาน 3–5 คำ แบบเร็ว |
| 2. ทบทวน (Core Review) | คำที่ถึงรอบ สลับสองแบบ: ฟังแล้วนึกความหมาย / เห็นไทยแล้วนึกคำอังกฤษ → ให้คะแนน Again / Hard / Easy → เติมคำ |
| 3. คำใหม่ (New Intake) | 5–7 คำ: ฟังเสียง → เลือกคำที่ได้ยินจาก 4 ตัวเลือก → ดูความหมายและตัวอย่าง → เติมคำ |
| 4. เก็บตก (Wrap-up) | คำที่ผิดหรือกด Again วันนี้ วนกลับมาจนถูกครบ 100% |

## รอบทบทวน (SRS)

- **Again** รีเซ็ตรอบ และส่งคำไปช่วงเก็บตกของวันนี้
- **Hard** ทบทวนพรุ่งนี้
- **Easy** ขยายรอบเป็น 3 → 7 → 14 → 30 → 60 → 120 วัน
- **Leech** ถ้าลืมครบ 3 ครั้ง ระบบจะเปลี่ยนไปใช้ประโยคที่ง่ายกว่า และแสดงภาพช่วยจำ

ความคืบหน้าเก็บไว้ในเบราว์เซอร์ของผู้เรียนเอง (localStorage) ไม่ได้ส่งขึ้น GitHub
ถ้าเปลี่ยนเครื่องหรือล้างข้อมูลเบราว์เซอร์ ความคืบหน้าจะหายไป

## โครงสร้าง

```
index.html        หน้าเว็บ (ใช้ Tailwind CSS ผ่าน CDN ไม่ต้อง build)
assets/srs.js     ตรรกะรอบทบทวนและการจัดคิวประจำวัน
assets/app.js     หน้าจอและลำดับการเรียน
data/words/       คลังคำศัพท์ 3,000 คำ (30 ชุด ชุดละ 100 คำ) เรียงตามความถี่การใช้
data/SCHEMA.md    รูปแบบข้อมูลและวิธีเพิ่มคำ
tools/check_words.py  ตัวตรวจไฟล์คำศัพท์ก่อน commit
```

## เปิดบนเครื่อง

ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (ดับเบิลคลิกไฟล์ HTML ตรงๆ จะโหลดคำศัพท์ไม่ได้)

```bash
python -m http.server 8000
```

แล้วเปิด http://localhost:8000

บนคอมพิวเตอร์มีคีย์ลัด: `Space` / `Enter` = เฉลยหรือไปต่อ, `1`–`4` = เลือกปุ่มคำตอบ
